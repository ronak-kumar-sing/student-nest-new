## 🔧 Troubleshooting

### Icons Not Showing?

**Mobile App:**
```bash
cd StudentNestApp
rm -rf .expo
rm -rf node_modules/.cache
npx expo start -c
```

**Website:**
```bash
cd Website
rm -rf .next
npm run dev
# Then hard refresh browser: Cmd+Shift+R
```

### Still Not Working?
1. Close all dev servers
2. Clear browser cache completely
3. Delete Expo Go app and reinstall
4. Restart your computer
5. Start fresh
