## 🆘 Troubleshooting

### Login fails with old email domain?
If you see an error like "user not found", ensure you're using:
- `demo.student@student-nest.live` ✅
- NOT `demo.student@studentnest.com` ❌

### Still having issues?
1. Check internet connection
2. Verify backend is accessible: https://www.student-nest.live
3. Restart the app
4. Clear app cache: Settings → App → StudentNest → Clear Cache

### Can't see demo buttons?
Make sure you're on the **Login** screen (not signup)
